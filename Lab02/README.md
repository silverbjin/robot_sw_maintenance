# 01. 오늘의 미션

소프트웨어를 바로 설치하지 않습니다.

먼저 개발 PC의 환경을 확인하고 다음 중 하나를 결정합니다.

```text
┌─────────────────────────────────────────────┐
│              설치 전 환경 점검              │
├─────────────────────────────────────────────┤
│                                             │
│  OS ──→ CPU ──→ Memory ──→ Storage ──→ Network
│                                             │
│                         ↓                   │
│                    결과 판정                │
│                  ↙          ↘              │
│              ✅ 정상       ⚠ 문제 발견      │
│                ↓              ↓             │
│            설치 진행        문제 조치        │
│                               ↓             │
│                            재검증            │
└─────────────────────────────────────────────┘
```

# Mission 11

# 이것이 실제 로봇이라면?

이번 실습에서는:

```text
개발 PC Client
      │
      │ 127.0.0.1
      ▼
같은 PC Server
```

실제 환경에서는:

```text
개발 PC                          Robot
┌───────────────┐          ┌───────────────┐
│ ROS 2 / Tool  │          │ ROS 2 / Node  │
│               │          │               │
│192.168.0.10   │          │192.168.0.20   │
└───────┬───────┘          └───────┬───────┘
        │                           │
        └──────── Router ──────────┘
```

개발 PC에서 실행:

```bash
ping -c 4 192.168.0.20
```

달라지는 것은 주로 **상대방 주소**입니다.

```text
이번 실습           실제 로봇

127.0.0.1     →     192.168.0.20
내 PC                Robot IP
```

그러나 점검 원리는 같습니다.

```text
IP 확인
 ↓
Interface 확인
 ↓
상대 주소 확인
 ↓
통신 요청
 ↓
응답 확인
```

# 기억해야 할 3가지

**① 개발 PC와 로봇은 하드웨어가 달라도 환경을 점검하는 원리는 같다.**

```text
OS → CPU → Memory → Storage → Network
```

**② 실제 설치 방법에는 차이가 있다.**

```text
Development PC              Robot SBC

x86_64                      aarch64
WSL / USB                   SD / eMMC / NVMe
PC Ubuntu                   제조사 Image
일반 Driver                 Robot HW Driver
```

**③ 이번에는 한 대의 PC에서 통신했지만 실제 로봇 통신도 원리는 같다.**

```text
이번 실습
Client ──→ 127.0.0.1 ──→ Server

실제 환경
PC ──→ Robot IP ──→ Robot
```

따라서 최종 학습 흐름은 **`명령 실행 → 결과 읽기 → 기록 → 판정 → 장애 조치 → 재검증`**입니다. 단순히 명령을 따라 치는 것보다, 학생이 각 단계마다 직접 상태를 표시하고 판단 근거를 기록하도록 만든 것이 핵심입니다.
