# 학생용 안내 — Lab10 사용자 피드백 기반 교육 개선

## 최종 목표

제공된 사용자 행동 기록과 Evidence를 분석하여 **사용자 피드백 기반 교육·매뉴얼 개선안**을 작성합니다.

## 중요한 규칙

1. 처음부터 원인을 정하지 않습니다.
2. 사용자에 대한 평가 대신 관찰 가능한 사실을 기록합니다.
3. Evidence에 없는 사실을 만들어내지 않습니다.
4. ROS 2 명령을 많이 적는 것보다 **왜 확인하는지와 다음 행동**을 설명합니다.
5. 개선 효과는 만족도가 아니라 실제 수행 변화로 평가합니다.

## 제출 파일

`templates/improvement_plan_template.md`를 복사하여 아래 형식으로 저장합니다.

```text
submission/학번_이름_improvement_plan.md
```
