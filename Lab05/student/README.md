# 학생용 실습 자료 — 5회차 업그레이드 준비

## 실습 목표

이번 실습에서는 실제 업그레이드를 수행하지 않는다. 현재 정상 상태를 기록하고, 6회차에서 수행할 Robot Application 변경 계획을 작성한 뒤 GO/NO-GO를 판단한다.

## 사용 순서

0. `02_setup_guide.md`
1. `04_student_workbook.md`
2. Git이 처음이면 `appendix_git_github_beginner.md`
3. 강사가 지정한 데모 Git 저장소에서 Baseline 확인
4. `../evidence/collect_all.sh`로 Evidence 수집
5. `../reports/` 템플릿 작성
6. 최종 판단 보고서 제출

## 6회차 예정 범위

- 유지: Ubuntu 22.04 / JetPack 6.x / ROS 2 Humble
- 변경: `myagv_bringup` 일부 변경, `myagv_monitor` 신규 추가
