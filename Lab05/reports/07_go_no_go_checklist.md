# GO / NO-GO Checklist

> 하나라도 필수 항목이 NO이면 NO-GO로 판단하고 보완 후 다시 확인한다.

| 구분 | 최종 점검 항목 | YES | NO | 근거 / Evidence |
|---|---|---:|---:|---|
| Baseline | 현재 정상 상태가 기록되어 있는가? | [ ] | [ ] | |
| Compatibility | Target과 현재 ROS 2 Humble 환경의 관계를 확인했는가? | [ ] | [ ] | |
| Backup | 복구에 필요한 자료를 확보했는가? | [ ] | [ ] | |
| Rollback | `pre-upgrade-v1`로 되돌아가는 방법이 명확한가? | [ ] | [ ] | |
| Upgrade Plan | 변경 범위·순서·검증 항목이 정의되어 있는가? | [ ] | [ ] | |

## 최종 3문장 점검

1. 현재 정상 상태를 정확하게 알고 있는가? YES / NO
2. 문제가 발생해도 이전 정상 상태로 돌아갈 수 있는가? YES / NO
3. 무엇을 어떤 순서로 변경할지 명확한가? YES / NO

- [ ] NO-GO
