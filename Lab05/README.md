# Lab05 학생 배포용 실습 패키지

5회차 목표는 **READY FOR UPGRADE**입니다. 실제 업그레이드는 수행하지 않습니다.

## 진행 순서

0. `student/02_setup_guide.md` 수행
1. `student/04_student_workbook.md` 수행
2. Git 초보자는 `student/appendix_git_github_beginner.md` 참고
3. `evidence/collect_all.sh`로 Evidence 수집
4. `reports/` 템플릿 작성
5. 최종 GO / NO-GO 판단 및 보고서 제출

## 6회차 예정 범위

- Ubuntu 22.04 / JetPack 6.x / ROS 2 Humble 유지
- `myagv_bringup` 일부 변경
- `myagv_monitor` 신규 추가

강사용 정답과 Target 구현 소스는 포함되어 있지 않습니다.
