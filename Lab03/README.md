# ROS 2 Humble Validation Lab

슬라이드 10, 11, 12, 13, 14, 15, 15-2에 대응하는 학생 실습 워크북과 강사 제공 ROS 2 패키지입니다.

## 구성

```text
ros2_humble_validation_lab/
├── README.md
├── STUDENT_WORKBOOK.md
├── INSTRUCTOR_DISTRIBUTION.md
└── provided_files/
    └── maintenance_check_pkg/
```

## 사용 순서

1. 강사는 `provided_files/maintenance_check_pkg`를 학생에게 배포합니다.
2. 학생은 `STUDENT_WORKBOOK.md`를 따라 실습합니다.
3. 소스 코드는 학생이 작성하지 않습니다.
4. 학생은 패키지 배치, 빌드, Overlay 적용, 통신 검증, 오류 진단에 집중합니다.
