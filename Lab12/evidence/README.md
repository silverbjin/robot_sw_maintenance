# Evidence 저장 폴더

`bash scripts/collect_evidence.sh` 실행 후 다음 파일이 생성됩니다.

- `E01_environment.txt`
- `E02_node_list.txt`
- `E03_topic_list.txt`
- `E04_topic_hz.txt`
- `E05_git_status.txt`
- `E06_git_diff.txt`
- `E07_git_log.txt`
- `E08_function_status.txt`
- `evidence_summary.md`

강사가 이미지 캡처를 요구하면 같은 ID를 사용하여 PNG로 추가합니다.

예: `E04_topic_hz.png`
