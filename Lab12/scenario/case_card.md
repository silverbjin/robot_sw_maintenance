# LAB12-CASE-01 — 유지보수 결과 관리 사례

## 상황

`myagv_monitor` 역할을 하는 모니터에서 LiDAR 센서 상태가 정상으로 표시되지 않는 문제가 발생했습니다.

점검 결과 `config/config.yaml`의 `lidar_port`가 실제 정상 기준과 다른 값으로 설정되어 있었습니다.

담당자가 포트 설정을 수정하고 관련 ROS 2 노드를 다시 실행하여 현재 기능은 정상 복구되었습니다.

## 현재 상태

- ROS 2 데모: 정상 실행 가능
- LiDAR Mock 데이터: 정상 수신 가능
- Monitor 기능: 정상
- 유지보수 Evidence: 아직 학생이 수집해야 함
- 유지보수 결과 보고서: 미작성
- 장기 운영 후속 조치: 미결정

## 학생 역할

새로운 장애를 해결하는 것이 아닙니다.

이미 복구된 시스템을 대상으로:

1. 정상 판단에 필요한 Evidence를 수집하고,
2. 유지보수 결과 보고서를 작성하고,
3. 다음 장애를 줄일 장기 운영 전략을 결정합니다.
