# 4회차 학생 배포용 실습 패키지

## 실습 순서

```text
student/04_student_workbook.md
        ↓
LAB 15 저속 제어
        ↓
LAB 16 센서 검증
        ↓
LAB 17 Gateway
        ↓
Safety 확인
        ↓
Evidence 수집
        ↓
reports/05_result_report_template.md
```

## 중요한 원칙

- 소스 코드를 작성하거나 수정하지 않는다.
- 강사가 제공한 Gateway와 도구를 실행한다.
- 저속 시험은 강사의 지시에 따라 수행한다.
- 장애 주입은 강사가 수행한다.
- 정상 여부는 **존재 → 데이터 → 실제 반응 → 안전성** 순서로 판단한다.

## 시작 문서

`student/04_student_workbook.md`

## 결과 제출

`reports/05_result_report_template.md`

Evidence는 `evidence/`에 저장한다.
